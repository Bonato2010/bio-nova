## 🔬 Conteúdo do Portal
1. **Introdução à Biotecnologia & Sustentabilidade:** A ciência celular a favor do planeta.
2. **Agricultura Regenerativa:** Fixação biológica de nitrogênio, biofertilizantes e microrganismos eficientes.
3. **Energias Limpas & Renováveis:** Biometano, etanol celulósico (2G) e microalgas fotossintéticas.
4. **Preservação & Biorremediação:** Enzimas degradadoras de poluentes e restauração de biomas.
5. **Bioeconomia Circular & Futuro:** Economia de ciclo fechado alinhada às metas da ONU e CTNBio.
6. **Nossa Equipe:** Apresentação dos integrantes da pesquisa com credenciais acadêmicas.

## 🚀 Como Executar Localmente
Este é um portal puramente estático (HTML5, CSS3, JavaScript ES6+). Pode ser aberto diretamente pelo navegador ou servido por qualquer servidor HTTP:

```bash
# Usando npx serve
npx serve .

# Ou usando Python 3
python -m http.server 8080
```

Acesse `http://localhost:8080` no navegador.
